# Документы ФЛОУ

Сюда кладутся PDF-сканы юридических и справочных документов. Файлы из этого
каталога доступны на поддомене https://app.flow-erp.ru/docs/<имя-файла> —
их можно посмотреть и скачать из меню «Документы» в шапке приложения.

Имена файлов — латиницей без пробелов (так ссылки работают без URL-кодирования).
При скачивании из меню файлу присваивается читаемое русское имя.

## Меню «Документы» в шапке

Список задаётся в `src/constants/documents.ts`.

| Файл                          | Документ                                                                 | Виден сотрудникам |
| ----------------------------- | ------------------------------------------------------------------------ | ----------------- |
| `license-agreement-offer.pdf` | Лицензионный Договор-Оферта                                              | нет               |
| `user-agreement.pdf`          | Пользовательское соглашение                                              | нет               |
| `admin-guide.pdf`             | Руководство администратора по получению доступа и настройке системы ФЛОУ | нет               |
| `user-guide.pdf`              | Руководство пользователя по работе в системе ФЛОУ                        | да                |
| `tracker-user-guide.pdf`      | Руководство пользователя по работе трекера ФЛОУ                          | да                |
| `tracker-description.pdf`     | Описание работы трекера рабочего времени ФЛОУ                            | нет               |
| `tracker-policy.pdf`          | Политика использования трекера рабочего времени ФЛОУ                     | нет               |
| `tracker-notice.pdf`          | Уведомление об использовании системы учета рабочего времени ФЛОУ         | нет               |

Владелец компании (роль `ADMIN`/`SUPERADMIN`) видит все документы, сотрудники —
только `user-guide.pdf` и `tracker-user-guide.pdf`.

| Файл                        | Документ                                                   |
| --------------------------- | ---------------------------------------------------------- |
